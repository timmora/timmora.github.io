Brandle

Developer & UI Designer — extended from a class project

View live → GitHub →
Overview

A daily + unlimited Wordle-like game: guess a mystery brand and get color-coded feedback across category, country of origin, founding year, revenue range, and employee count.

What I built

The full React experience — guess flow, validation, win/lose states, shareable results, and stats — tuned to feel fast, polished, and replayable.

Key features
  • Multi-attribute feedback (green / yellow / gray) plus higher/lower hints on numeric fields
  • Daily puzzle (same answer per day) and Unlimited mode for replay
  • Difficulty modes with different thresholds and limits
  • Hints and hard-mode constraints
  • Local stats and streak tracking (win rate, distribution, streaks)
  • Auth + leaderboard-ready data model in Supabase
Tech stack
React 18 React Router Supabase Postgres JavaScript MUI / Emotion Bootstrap
Data & backend

Supabase hosts everything — no custom server. Brand rows come from a brands table; user results and stats can be written for persistence and leaderboards.

Deployment

Vercel, with SPA routing so routes like /game load correctly.

What I'm proud of

Turning a simple guessing mechanic into a real game loop: clear UX, meaningful feedback, and retention hooks — daily puzzle, streaks, stats, and unlimited play.
